4. Behavioral Screening to Educational Translation Pipeline

A central innovation evaluated by the jury is our Educational Translation Pipeline. Clinical screening datasets like the Autism Spectrum Disorder Screening Dataset (AQ-10 Child & Adolescent) and the ICMR Pediatric Neurodevelopmental Tool carry medical stigmatization risks. NeuroQuest strips away all clinical diagnostics and translates behavioral observations into classroom accommodations.

  • Stage 1 (Clinical Extraction): Extract validated screening items measuring sensory reactivity, attention switching, and literal language.
  • Stage 2 (Diagnostic Purging): Permanently delete clinical cut-off scores, ASD severity scores, medication logs, and EEG flags. Zero medical labels are stored or shown.
  • Stage 3 (Pedagogical Re-framing): Convert diagnostic items into observable learning support questions (e.g. "Difficulty following long conversations" becomes "Formats companion dialogues into direct, structured cards").
  • Stage 4 (Support Dimension Vector): The 20-question caregiver baseline calculates 10 Educational Support Dimensions displayed on an interactive radar chart.

5. Learning Analytics & Real-Time Telemetry Models

During live quest sessions, NeuroQuest evaluates high-frequency interaction telemetry using a trained Random Forest classifier. Trained using benchmarks from UCI Student Behavior and EdNet interaction logs, the model detects learner cognitive states in real time without facial recording.

  • Model Architecture: Random Forest Classifier (Scikit-Learn) with Standard Scaler normalization.
  • Model Accuracy: 99.25% Cross-Validation Test Accuracy across three non-medical interaction states.
  • State 1: FOCUSED (State ID 0): Rapid correct progression, steady click rate, low idle ratio. UI maintains current reward velocity.
  • State 2: ATTENTION_DRIFT (State ID 1): Prolonged hesitation, off-screen gaze drift, irregular click spikes. UI automatically engages Focus Mode and re-anchors interest themes.
  • State 3: POSSIBLE_FATIGUE (State ID 2): Slow response times, repeated incorrect attempts. UI transitions to Calm Mode and presents a non-punitive 1-minute breathing breather.
