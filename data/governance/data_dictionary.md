# Data Dictionary

## Datasets

### NCERT_Class7_Science_Math
* **Source:** NCERT / DIKSHA / ePathshala
* **Description:** Curriculum metadata and structure for Class 7 Science and Mathematics.
* **Fields:**
  * `subject` (String): The subject (e.g., Science, Mathematics)
  * `class_level` (Integer): The class level (e.g., 7)
  * `chapter_id` (String): Unique identifier for the chapter
  * `chapter_title` (String): Title of the chapter (e.g., "Nutrition in Plants")
  * `topics` (List): Sub-topics covered in the chapter
  * `learning_outcomes` (List): Expected learning outcomes for the chapter
  * `source_url` (String): Link to the official resource (ePathshala/DIKSHA)
